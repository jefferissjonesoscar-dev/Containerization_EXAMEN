# HairBook — Gestion de rendez-vous pour salon de coiffure

HairBook est une application web développée avec Flask et MySQL.
Elle permet de gérer les clients, coiffeurs, prestations et rendez-vous
d'un salon de coiffure via une interface élégante.

P.S. Ce projet m'a coûté plus d'heures de travail que de coupes de cheveux dans ma vie.
